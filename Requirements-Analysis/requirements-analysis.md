# Requirements Analysis
Requirements Analysis is the first step in the software design process. It defines exactly what the system needs to do before any code is written.

## Functional Requirements
The Cinema Booking System should allow:
1. Customer enters the cinema system.
2. Customer views available movies.
3. Customer selects a movie/show.
4. Customer selects a screen.
5. Customer views available seats.
6. Customer selects a seat.
7. System calculates ticket price.
8. Customer selects a payment method.
9. System processes payment.
10. System creates the booking.
11. System generates the ticket.
12. Ticket is printed.

## Payment Requirements
The system must support the following payment methods securely:
- UPI
- Card
- Cash
